# Dynamic

Dynamic is a wallet infrastructure platform for fintech, crypto, and stablecoin applications — embedded non-custodial wallets, 800+ external wallet connections, distributed (TSS-MPC) key management, and onchain products (payments, trading, yield, global money movement) delivered from low-level REST APIs up to prebuilt UI SDKs.

- Docs: https://www.dynamic.xyz/docs
- API Reference: https://www.dynamic.xyz/docs/api-reference (base `https://app.dynamicauth.com/api/v0`)
- Dashboard / Sign up: https://app.dynamic.xyz/
- Status: https://status.dynamic.xyz/
- GitHub: https://github.com/dynamic-labs
- MCP server: https://www.dynamic.xyz/docs/mcp

Backed by: a16z. Acquired by Fireblocks (October 2025).

Enriched by the API Evangelist enrichment pipeline: identity, SDKs/packages, CLI, MCP, authentication, conventions, lifecycle, changelog, webhooks, conformance/compliance, security probes, and UI components.
